🌐 Proyecto Web Grupal – HTML y CSS
📌 Descripción del proyecto

Este proyecto consiste en desarrollar un sitio web utilizando HTML5 y CSS3, como parte de un trabajo en clases.

El trabajo se realizará en grupos de 3 integrantes. Cada integrante deberá crear su propia página web con un tema de libre elección. Posteriormente, las tres páginas deberán conectarse entre sí mediante un menú de navegación.

🎯 Objetivo

Poner en práctica los conocimientos adquiridos en clase sobre HTML y CSS, desarrollando páginas web con diseños propios y fomentando el trabajo en equipo.

👥 Integrantes y responsabilidades

Cada integrante será responsable de desarrollar una página web independiente.

Integrante	Responsabilidad
Integrante 1	Crear su propia página web con un tema libre.
Integrante 2	Crear su propia página web con un tema libre.
Integrante 3	Crear su propia página web con un tema libre.
📋 Requisitos del proyecto

Cada página deberá cumplir con los siguientes requisitos:

Utilizar HTML para la estructura de la página.
Utilizar CSS para el diseño y los estilos.
Tener un tema de libre elección.
Incluir títulos, textos e imágenes relacionados con el tema.
Contar con un diseño ordenado y atractivo.
Tener un menú de navegación para conectarse con las demás páginas.
🔗 Menú de navegación

Las tres páginas deberán estar conectadas mediante un menú que permita:

Acceder a la página del integrante 1.
Acceder a la página del integrante 2.
Acceder a la página del integrante 3.
Navegar fácilmente entre las diferentes páginas.

🤝 Trabajo en equipo

Cada integrante desarrollará su página de manera individual. Al finalizar, se unirán los trabajos para crear un solo sitio web, asegurándose de que el menú de navegación conecte correctamente todas las páginas.

✅ Resultado esperado

Obtener un sitio web grupal compuesto por tres páginas independientes, cada una con un tema y diseño diferente, conectadas mediante un menú de navegación común.
